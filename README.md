## ✨ 주요 모바일 편의 기능
1. **상단 고정 3탭 전환:** 화면 맨 위에서 `1. 공항➔우메다`, `2. 우메다⇄교토`, `3. 전체 노선도` 탭을 한 번의 터치로 전환할 수 있습니다.
2. **글자 크기 조절 (`기본` / `크게+` / `특대++`):** 우측 상단 버튼으로 부모님 시력에 맞춰 글씨 크기를 즉시 키울 수 있습니다.
3. **세부 목차 칩 바 & 표 좌우 이동 버튼:** 탭 바로 아래에서 원하는 단계로 즉시 이동할 수 있으며, 모든 비교표 상단에 `[◀ 왼쪽] [오른쪽 ▶]` 이동 버튼이 제공됩니다.
4. **노선도 전용 확대/이동 뷰어 & 사진 터치 전체화면 확대:** 노선도를 `+1.8배 / +2.8배`로 키워 상하좌우로 밀어 보거나 원본 고화질 이미지·공식 PDF를 새 창에서 열 수 있으며, 모든 현장 안내 사진을 터치하면 전체화면으로 확대됩니다.
5. **인쇄/오프라인용 PDF 다운로드:** 각 탭 상단에서 고화질 PDF 원본(`간사이공항_우메다_가는법.pdf`, `우메다_교토_가는법.pdf`, `오사카_전체_노선도.pdf`)을 바로 열거나 저장할 수 있습니다.
