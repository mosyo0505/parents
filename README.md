# 🇯🇵 부모님 오사카·교토 여행 모바일 가이드

부모님께서 스마트폰(안드로이드·아이폰)으로 언제 어디서든 편하게 보실 수 있도록 제작한 **모바일 탭 전환형 초밀착 사진 가이드**입니다.

## 📱 모바일 접속 주소 (GitHub Pages)
- **메인 모바일 가이드 (탭 통합본):** `https://mosyo0505.github.io/parents/`
  - **탭 1 (`✈️ 1. 간사이공항 ➔ 우메다`):** 비행기 하차 · 입국심사 · 리무진버스/하루카/간쿠쾌속 탑승 · 이비스 오사카 우메다 호텔 찾아가는 길 · 안드로이드 교통카드 가이드
  - **탭 2 (`⛩️ 2. 우메다 ⇄ 교토·청수사`):** 한큐전철 특급 · JR 신쾌속 · 청수사 도보/택시/버스 및 하산 코스 · 저녁에 교토에서 우메다(이비스 호텔) 돌아오는 법

## ✨ 주요 모바일 편의 기능
1. **상단 고정 탭 전환:** 화면 맨 위에서 `공항 ➔ 우메다` 탭과 `우메다 ⇄ 교토·청수사` 탭을 한 번의 터치로 전환할 수 있습니다.
2. **글자 크기 조절 (`기본` / `크게+` / `특대++`):** 우측 상단 버튼으로 부모님 시력에 맞춰 글씨 크기를 즉시 키울 수 있습니다.
3. **세부 목차 가로 스크롤 바:** 탭 바로 아래에서 원하는 단계(리무진버스, 한큐전철, 청수사, 복귀법 등)로 바로 이동할 수 있습니다.
4. **사진 터치 시 전체화면 확대:** 모든 현장 안내 사진을 터치하면 큰 화면으로 확대되어 이정표 글씨까지 선명하게 볼 수 있습니다.
5. **인쇄/오프라인용 PDF 다운로드:** 각 탭 상단에서 고화질 PDF 원본(`간사이공항_우메다_가는법.pdf`, `우메다_교토_가는법.pdf`)을 바로 열거나 저장할 수 있습니다.
