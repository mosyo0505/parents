이 파일은 이전 세션에서 논의된 **부모님 오사카·교토 여행 계획, 확정 사항, 제작 완료된 가이드 문서 및 디자인 규칙**을 요약해 둔 문서입니다. 다음 세션에서 작업을 이어갈 때 이 문서를 참고하여 일관성 있게 진행하면 됩니다.

## 📌 1. 여행 기본 정보 및 핵심 확정 사항

* **여행 대상:** 부모님 (시니어 맞춤형 동선·가독성 최우선 고려)
* **스마트폰 환경:** **안드로이드(갤럭시 등) 사용자**
  * 일본 외 해외 출시 안드로이드폰은 일본 독자 규격(`Osaifu-Keitai / FeliCa`) 미지원으로 모바일 파스모/스이카 발급 불가.
  * **확정된 교통카드 전략 (2가지 병행 추천):**
    1. **1순위 (간사이 철도·지하철):** 한국에서 쓰던 **트래블카드(트래블월렛/트래블로그 등) 또는 해외결제 신용카드 실물 터치결제(컨택리스)** (오사카 메트로, 한큐전철, 난카이 전철 등 개찰구 은색 리더기 터치)
    2. **2순위 (교토 시내버스·JR·편의점 만능):** 간사이공항 역 파란색·분홍색 발매기에서 **실물 ICOCA 카드** 발급(2,000엔 = 보증금 500엔 + 충전 1,500엔, 현금 충전 방식, 개찰구 파란색 패드 터치)
* **최종 확정 숙소:** **이비스 오사카 우메다 (ibis Osaka Umeda / イビス大阪梅田)**
  * **위치 특징:** 우메다 지하상가 **`화이티 우메다(Whity Umeda) 7-72번 출구`** 바로 앞 직결 / 지상 이동 시 빨간색 **`HEP FIVE 대관람차`** 바로 옆 오기마치도리 큰길변.
  * 우메다 주요 역(JR 오사카역, 한큐 오사카우메다역, 오사카 메트로 우메다역·히가시우메다역)에서 도보 4~6분 거리.

## 🎨 3. 가이드 문서 작성 및 디자인 표준 (다음 문서 제작 시 준수)

1. **부모님 친화적 레이아웃:**
   * 큼직한 글씨 크기, 높은 명도 대비, 핵심 키워드 하이라이트 처리.
   * 현지에서 역무원·택시기사에게 바로 보여줄 수 있는 **일본어 한자 병기 박스** 필수 포함 (예: `特急 京都河原町`, `新阪急ホテル`, 택시 행선지 문구 등).
2. **시각 자료 현지화:**
   * 단계별(STEP) 실제 공항/역사/개찰구/승강장/랜드마크 사진을 로컬 `images/` 폴더에 다운로드하여 HTML에 상대 경로(`images/...`)로 연결.
3. **HTML + PDF 동시 제공:**
   * HTML 수정 후 반드시 Google Chrome Headless 명령어로 A4 사이즈 배경 포함 PDF를 생성하고, 페이지 잘림(page-break)이 없는지 시각적으로 검증.
   * PDF 변환 명령어 예시:
     ```bash
     "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
       --headless --disable-gpu --no-pdf-header-footer --print-to-pdf-no-header \
       --print-to-pdf="파일명.pdf" "파일명.html"
     ```
